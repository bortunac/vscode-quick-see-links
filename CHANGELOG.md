# Changelog

## 0.1.0

- `@see path#name` and `@see path#Class.method` links, resolved through the target file's outline.
- **Copy @see Link** in the editor context menu: copies a workspace-relative link to the symbol under the cursor.

## 0.0.1

- `@see` / `@link` comments with `path[:line[:col]]` become clickable links in any file type.
